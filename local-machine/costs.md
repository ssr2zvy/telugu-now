# Costs

## Fly.io and Tigris

**Billing:** [Fly.io billing](https://fly.io/dashboard/personal/billing)

Fly.io hosts the Telugu Now server, persistent data volume, networking, and deployments. Tigris stores the corpus database and audio objects. Tigris usage is billed through Fly.io, so both services appear on the same Fly.io bill. We pay for machine runtime, persistent storage, network usage, builds, and Tigris storage and requests.

## GitHub Codespaces

**Billing (Codespaces under "Metered usage"):** [GitHub billing and usage](https://github.com/settings/billing)

GitHub Codespaces provides the development environment used to build, test, and deploy Telugu Now. GitHub Actions runs repository automation and deployment workflows. We pay for Codespaces compute and storage and for Actions minutes and artifact storage beyond included allowances.

## GitHub Actions

**Billing (Actions under "Metered usage"):** [GitHub billing and usage](https://github.com/settings/billing)

GitHub Actions runs repository automation and deployment workflows. We pay for Codespaces compute and storage and for Actions minutes and artifact storage beyond included allowances.

## GitHub AI

**Billing:** [GitHub billing and licensing](https://github.com/settings/billing/ai_usage)

GitHub AI, including GitHub Copilot, is used for AI-assisted software development. We pay for the applicable Copilot subscription or assigned license and any premium request usage that is not included in the plan.

## Claude AI

**Billing:** [Claude billing](https://platform.claude.com/dashboard)

Claude AI is used for AI-assisted development, analysis, and planning. We pay for the Claude subscription and, if applicable, any separately enabled Anthropic API usage associated with the account.

## Pollinations

**Billing:** [Pollinations Pollen dashboard](https://enter.pollinations.ai/pollen)

Pollinations provides server-side image generation for word illustrations using `microsoft/mai-image-2.5-flash`. We pay for Pollen credits consumed by generation and regeneration requests; displaying an already saved image does not make another paid generation request.

## Serper

**Billing:** [Serper dashboard](https://serper.dev/dashboard)

Serper provides image-search results used to find licensed word illustrations. We pay for API search requests or credits consumed while searching result pages. Downloaded image files are stored by Telugu Now rather than hosted by Serper.
